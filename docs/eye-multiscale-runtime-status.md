# Eye multiscale runtime status

This candidate restores the already-tested Eye multiscale runtime foundation on the latest authoring main without changing existing production anatomy or renderer behavior.

## What this enables
- Educational navigation can represent the Eye from organ to suborgan, tissue, cellular and molecular scales.
- Scale changes are intentionally adjacent; skipping directly across multiple scales is blocked.
- Eye structures can be handed to the existing renderer only through exact canonical identity resolution.
- Runtime mesh targeting requires an exact source/base-name match and a source that is already loaded.

## What this does not claim
- It does not make reference-only microscopic or molecular content into verified 3D geometry.
- It does not prove anatomical completeness, licensing, qualified academic review or publication readiness.
- It does not infer physiology, disease, lesion location or patient-specific findings.
- It does not create another renderer or load another anatomy asset.

## Product status
This is infrastructure for a continuous large-to-small Eye learning experience. It is not, by itself, a declaration that the Eye Gold Standard is complete. Anatomy/content coverage, physiology, pathology, pharmacology, imaging, procedures, visual quality and human review remain separately auditable product areas.
