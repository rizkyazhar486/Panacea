# Deep Human Lab — PanaceaMed Multiscale Research Architecture

## Product intent
Deep Human Lab is a continuous research surface spanning atomic interactions → molecules → genome → organelles → cells → tissue → organs → body-wide networks → cognition → consciousness research. It is explicitly a research/education layer, not a claim that one scale fully explains another.

## Product principles
1. **Multiscale continuity** — every layer links upward and downward to adjacent scales.
2. **Mechanism ≠ outcome** — mechanistic plausibility is displayed separately from evidence of clinical benefit.
3. **Uncertainty is visible** — every causal bridge should expose confidence, missing data, assumptions, and competing explanations.
4. **Genomic safety** — simulations may explain consequences of edit classes but must not output guide sequences, delivery recipes, culture parameters, dosing, or wet-lab optimization.
5. **Voluntary cognition only** — no coercive persuasion or manipulation. Cognitive modules model self-directed attention, stress regulation, sleep, motivation, recovery, learning, and decision-making.
6. **Consciousness is contested** — represent Global Neuronal Workspace, Recurrent Processing, Integrated Information and other theories as competing explanatory frameworks rather than settled facts.
7. **Research maturity is not a single AI confidence score** — separate idea, mechanism, in-silico, preclinical, clinical, and real-world evidence.

## Core surfaces
### 1. Human Scale Continuum
Interactive scale selector with scientific questions appropriate to each scale.

Example equations shown as educational anchors:
- Atomic: `E = hν`
- Ligand/receptor occupancy: `Occupancy = [L] / ([L] + Kd)`
- Thermodynamics: `ΔG = ΔH − TΔS`
- Cell-state dynamics: `dX/dt = production − degradation + transport`
- Diffusion: `J = −D∇C`
- Genotype/environment conceptual model: `P = G + E + G×E + ε`

These are explanatory models, not patient-specific predictions.

### 2. Genome Consequence Sandbox
Safe conceptual edit classes:
- Variant correction
- Expression decrease
- Expression increase
- Loss-of-function model

Output chain:
`variant → transcript → protein → pathway → cell state → tissue phenotype → organ function → patient outcome`

Every step contains uncertainty and context dependence.

### 3. Cognitive State Engine
Initial heuristic index:
`Focus Index = 0.30A + 0.25S + 0.20M + 0.15Rs + 0.10Rr`

Where:
- `A` = attention stability
- `S` = sleep sufficiency
- `M` = intrinsic motivation
- `Rs` = stress-regulation capacity
- `Rr` = recovery reserve

This is a transparent product heuristic for experimentation, not a validated medical scale. It should later be replaced or calibrated against prospective data.

### 4. Consciousness Theory Comparator
Each theory should expose:
- proposed mechanism
- expected neural signatures
- falsifiable predictions
- observations it explains well
- observations that challenge it
- evidence maturity

The UI should avoid presenting philosophical or neuroscientific controversy as solved.

### 5. Invention & Hypothesis Forge
Input: a research question.
Output:
- falsifiable hypothesis
- mechanistic bridge
- alternative hypothesis
- counterfactual observation
- measurable intermediate endpoints
- study design ladder
- anticipated failure modes
- evidence maturity

The invention engine should reward disconfirming predictions, not only supportive evidence.

## Future integration targets

- Genome Lab: link directly into Genome Consequence Sandbox.
- Cell Lab: link organelle/cell states into the multiscale continuum.
- Molecular Lab: expose receptor occupancy, conformational state, and molecular uncertainty.
- Pusat Jiwa: expose voluntary cognitive-state tools only.
- Data Lab: permit research hypotheses to become analysis notebooks and prospective validation plans.

## Validation gates
- No generated sequence-specific gene-editing instructions.
- No coercive cognitive manipulation instructions.
- Every heuristic formula labeled heuristic unless validated.
- Every clinical claim has provenance and evidence maturity.
- Cross-layer causal arrows require an evidence citation or are visually marked as hypothetical.
- Accessibility: reduced motion, mobile layout, keyboard activation, readable contrast.
