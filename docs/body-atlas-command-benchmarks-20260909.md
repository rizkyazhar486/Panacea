# Body Atlas Command — benchmark contract

This file records the two external references that are mandatory design benchmarks for Panacea Body Atlas Command.

- Anatomy interaction benchmark: https://github.com/thebuggeddev/anatomy
- Breath workspace benchmark: https://breath-atlas.thebuggeddev.chatgpt.site/

## Integration rule

Panacea must learn from interaction patterns, not copy source code, models, textures, medical prose, or other assets. The `thebuggeddev/anatomy` repository currently has no declared repository license in GitHub metadata, so its implementation and assets are treated as reference-only unless a compatible license is independently verified later.

The resulting Panacea feature must use Panacea's existing anatomy renderer, source-node provenance, Z-Anatomy-derived assets, mobile WebGL safeguards, and accessibility/reduced-motion rules.

## Atlas Command intent

The experience should feel like a high-end command console: fast navigation, structure/system focus, keyboard command access, clear state, low visual clutter, and direct hand-off into the existing anatomy, structure finder, physiology-reference, and study workspaces.

This is not represented as AGI, autonomous diagnosis, or a clinical decision system. "Command" describes interaction quality only.

## Breath Atlas safety boundary

Breath Atlas is an educational reference doorway into the existing reviewed physiology workspace. It must not:

- claim to measure a patient's respiration;
- infer disease, oxygenation, ventilation, or treatment;
- fabricate respiratory rates or thresholds;
- deform source anatomy to pretend it is measured physiology;
- introduce new clinical physiology claims without Academic Accuracy Gate and qualified human review.

The source anatomy remains dimensionally stable. Any future physiologic animation needs evidence-bearing rig/morph data and review before publication.
