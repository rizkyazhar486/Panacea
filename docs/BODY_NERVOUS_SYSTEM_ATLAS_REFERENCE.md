# Nervous-system atlas mandatory reference contract

Panacea Body Exposure treats `aycibatuhan/nervous-system-atlas` as a mandatory external reference for nervous-system atlas architecture, interaction design, quality controls, and provenance patterns. It is not a blanket permission to copy its meshes, volumes, text, or generated data.

## Required patterns

The nervous-system implementation must preserve these capabilities as design requirements: an explicit coordinate/reference frame; synchronized 3D and section imaging only when registration is documented; cranial/peripheral/autonomic nervous-system hierarchy; tract/pathway navigation with ordered stations and crossings; sourced arterial-territory overlays; brain-to-spinal-cord continuity; educational lesion/syndrome scenarios; citation provenance; redistribution-license gating; explicit academic-review state; and a hard block on patient-specific inference from reference-atlas interactions.

## Safety and publication boundary

Reference-space alignment is not patient registration. A reference atlas selection, pathway, territory, or lesion marker must never become measured patient localization, diagnosis, prognosis, treatment advice, surgical guidance, or a claim about an individual's anatomy.

`referencePublication` therefore requires declared frame, registration evidence, geometry/imaging/pathway provenance, citation coverage, redistribution approval, AI disclosure, and a patient-inference block. `verifiedBiomedicalPublication` additionally requires actual approved academic review. Metadata completeness or AI generation never substitutes for expert review.

## Licensing boundary

The external reference describes separate public and restricted/private data paths. Panacea must independently inspect every asset's provenance and redistribution/derivative rights before importing or publishing anything. Restricted, non-commercial, no-derivatives, unlicensed, or otherwise non-redistributable source material remains excluded from public Panacea builds.

## Implementation relationship

This contract complements `brainCnsMacroWave1.ts`. The macro wave defines broad nervous-system inventory; this contract defines the quality, registration, provenance, interaction, and publication constraints that later nervous-system waves must satisfy.
