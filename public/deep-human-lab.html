Research-level engines

Each engine exposes uncertainty instead of hiding it.

Microscopy

Virtual tissue lens

Navigate organ → tissue → cell → organelle → molecular process while keeping morphology, function and pathology as separate overlays.

Atomic / molecular

Interaction field

Visualize charge, bond energy, receptor occupancy and diffusion as model states. It teaches mechanisms without pretending atoms alone predict clinical outcomes.

Invention

Counterfactual engine

Ask “what would have to be true?” then generate measurable intermediate predictions before any intervention is treated as plausible.

Genomics

Genome consequence sandbox

Explore conceptual edit classes and downstream uncertainty without exposing wet-lab instructions, guide sequences, delivery recipes or experimental parameters.

Cognition

Voluntary state control

Model sleep, arousal, stress, motivation and attentional control as interacting constraints. No coercive “mind control”; only self-directed regulation and measurement.

Consciousness

Theory comparison

Compare global-workspace, recurrent-processing and integrated-information viewpoints as competing explanatory frames, not settled biological facts.

Consciousness research layer

Multiple theories, explicit disagreement.

Global workspace

Broadcast hypothesis

Conscious access is modeled as information becoming globally available across otherwise specialized processors.

Recurrent processing

Local recurrent hypothesis

Conscious perception is linked to recurrent cortical processing rather than only feed-forward sweeps.

Integrated information

Integration hypothesis

Consciousness is related to intrinsic causal integration. The framework is influential and heavily debated; the UI should make that controversy visible.
