# Performance Resilience Profile

Panacea separates **objective task-performance retention** from **psychometric/self-report resilience constructs**.

Objective performance asks: how much of a repeatable benign task is retained under fatigue, pressure, load, heat, sleep loss or other defined context?

Higher-is-better task:
`retention = pressured / baseline`

Lower-is-better time task:
`retention = baseline / pressured`

A cross-domain OPRI is only shown after at least three distinct task classes are represented:

`OPRI = mean(dimensionRetention) × (0.75 + 0.25 × dataConfidence)`

OPRI is not a personality trait, diagnosis, employability standard, military/police fitness-for-duty decision, or universal mental-toughness truth.

Psychometric evidence stays separate and must retain instrument, version, population validation and citation.
