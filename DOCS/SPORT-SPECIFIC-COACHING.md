# Sport-Specific Coaching Playbooks

Universal Sport OS provides metrics and scientific graph contracts. Sport-specific coaching converts those measurements into repeatable training procedures.

Initial playbooks:
- tennis;
- baseball;
- Formula racing;
- MotoGP;
- road running;
- road cycling;
- pool swimming;
- triathlon/Ironman;
- HYROX;
- scuba diving;
- freediving;
- tactical fitness.

Each playbook contains:
1. priorities;
2. procedures;
3. progression;
4. metrics to track;
5. reassessment schedule;
6. explicit safety boundary.

The playbooks are intended to be selected only after Population Safety permits performance optimization and source-valid measurements exist.
